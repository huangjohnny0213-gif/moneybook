# 郵局通知信自動匯入

郵局每次從帳戶扣款都會寄通知信到 Gmail。這個功能讓 App 在打開時去 Gmail 抓這些信，
把金額與日期整理成**待確認**清單，你只要選分類、按確認。

## 運作方式

```
郵局 ──寄信──▶ 你的 Gmail
                  ▲
                  │ 只讀郵局寄來、主旨含「扣款通知／交易通知／繳費通知」的信
                  │
        你帳號裡的 Apps Script（apps-script/Code.gs）
                  ▲
                  │ App 打開時帶著密碼來問：某個時間之後有哪些信？
                  │
            手機上的記帳本 ──▶ 解析 ──▶ 設定頁的「郵局通知待確認」
```

- **沒有第三方伺服器。** Apps Script 跑在你自己的 Google 帳號裡，資料只從你的 Gmail
  流到你的手機。
- **不會自動入帳。** 每一筆都要你選分類按確認，轉帳給自己或繳卡費這類不算花費的，按略過。
- **這是選配功能。** 沒設定、或手機沒網路時，App 其他部分照常離線可用。

## 目前認得的信

| 信 | 抓得到 | 抓不到 |
|---|---|---|
| 連結帳戶付款服務扣款通知（LINE Pay 綁郵局帳戶） | 金額、日期 | **店名**：信裡只寫「連加電子支付」，所以每筆都要自己選分類 |
| 行動郵局交易通知（轉帳，含 Taiwan Pay 掃碼轉帳） | 金額、日期、附言 | 對方是誰：信裡只有遮住的帳號 |
| 全國性繳費通知 | 金額（含手續費）、日期、收款銀行 | — |

App 會記住每一種付款上次選的分類，下一筆預先選好。例如「LINE Pay」上次選了飲食，
下一筆 LINE Pay 就預選飲食；附言相同的轉帳也一樣。

看不懂的信不會變成帳，只會在設定頁列出主旨，方便之後補上解析規則。

## 設定步驟

建議用電腦做，大約十分鐘。

### 1. 建立 Apps Script

1. 用收郵局通知的那個 Google 帳號打開 <https://script.google.com>，按「新專案」。
2. 左上角的「未命名的專案」改成「記帳本郵件橋接」（名字隨意）。
3. 把編輯區原本的內容全部刪掉，貼上這個 repo 的
   [`apps-script/Code.gs`](../apps-script/Code.gs) 全文，按儲存（磁碟片圖示）。

### 2. 產生密碼並授權

1. 上方工具列的函式選單選 `setup`，按「執行」。
2. 跳出授權視窗 → 選你的帳號。
3. 出現「**Google 尚未驗證這個應用程式**」是正常的：這是你自己寫給自己用的程式，
   沒有送 Google 審核。按「進階」→「前往記帳本郵件橋接（不安全）」。
4. 權限頁會寫類似「讀取、撰寫、傳送及永久刪除你在 Gmail 中的所有電子郵件」的字樣。
   這是 Apps Script 讀信功能綁定的權限，沒辦法只要「讀」。程式實際做的事就是
   `Code.gs` 裡那幾十行：搜尋郵局寄來的信、讀內文，不會寫、寄或刪任何信。按「允許」。
5. 下方「執行記錄」會出現兩行：
   - `密碼（貼到 App 裡）：xxxxxxxx…` → 複製這串，等一下要用
   - `最近七天找到 N 封郵局扣款／交易通知。` → N 是 0 也沒關係，只代表最近沒扣款

### 3. 部署成網頁應用程式

1. 右上角「部署」→「新增部署作業」。
2. 左邊「選取類型」的齒輪 → 「網頁應用程式」。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（不是「擁有 Google 帳戶的所有人」）
4. 按「部署」，複製「網頁應用程式」底下那串網址，結尾是 `/exec`。

「所有人」聽起來很可怕，但沒有密碼的請求只會拿到 `unauthorized`。
選「擁有 Google 帳戶的所有人」反而不能用：App 發出的請求不會帶你的 Google 登入狀態。

### 4. 填進 App

App →「設定」→「郵局通知」→ 貼上網址與密碼 →「儲存並同步」。

第一次同步會抓最近七天的信。已經手記過的那幾筆，在待確認清單裡按略過就好。

## 之後

- **App 每次打開都會自動同步**，不必做任何事。有新的待確認時，「設定」分頁會出現紅點。
- **換手機**：備份檔**不含**網址與密碼（那是讀你信箱的鑰匙，不該跟著備份檔到處走）。
  新手機還原備份後，到設定頁重新貼一次。
- **密碼外洩了**：Apps Script 編輯器左邊齒輪「專案設定」→ 最下面「指令碼屬性」，
  把 `TOKEN` 改成新的一串，再到 App 裡更新。舊密碼立刻失效。
- **`Code.gs` 有更新時**：貼上新版本後，「部署」→「管理部署作業」→ 鉛筆圖示 →
  版本選「新版本」→「部署」。網址不變，App 不用改。
- **不想用了**：App 裡按「中斷連線」，再到 Apps Script「部署」→「管理部署作業」→ 封存。
